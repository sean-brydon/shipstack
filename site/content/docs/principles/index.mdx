**What it is.** One-rule files `/shipit` reads when a decision calls for one, and names in its reply.

**Why.** They cost no context until one applies, and you can steer by name ("apply prove it works").

## Core

| principle | the rule |
|---|---|
| [Laziness Protocol](/principles/laziness-protocol) | Bias to deletion and the smallest change that solves the problem. |
| [Foundational Thinking](/principles/foundational-thinking) | Before writing logic: core types and data structures, scaffold-vs-feature sequencing, what concurrent actors share. |
| [Redesign From First Principles](/principles/redesign-from-first-principles) | Redesign as if it had been foundational from day one. |
| [Attack the Premise](/principles/attack-the-premise) | Take a census of which actors hold the imbalance before the next fix, then question the premise. |
| [Subtract Before You Add](/principles/subtract-before-you-add) | Remove dead weight first, then build on the simpler base. |
| [Minimize Reader Load](/principles/minimize-reader-load) | Count layers and hidden state, collapse one-caller wrappers, shrink mutable scope. |
| [Outcome-Oriented Execution](/principles/outcome-oriented-execution) | Converge on the target architecture, don't preserve throwaway compatibility states. |
| [Experience First](/principles/experience-first) | Choose user delight over implementation convenience. Fewer, polished features. A feature that feels gimmicky gets cut, not polished. |
| [Exhaust the Design Space](/principles/exhaust-the-design-space) | Build 2-3 competing prototypes and compare before committing. |
| [Build the Lever](/principles/build-the-lever) | Build the tool that does or proves it (codemod, script, generator), not by hand. The tool is the artifact a reviewer reruns. |

## Architecture

| principle | the rule |
|---|---|
| [Model the Domain](/principles/model-the-domain) | Encode the domain in a structure (state machine, typed model, table or registry, reducer, boundary) instead of scattered conditionals. |
| [Boundary Discipline](/principles/boundary-discipline) | Guards at system boundaries, trust internal types, keep business logic pure. |
| [Type System Discipline](/principles/type-system-discipline) | Make illegal states unrepresentable, brand primitives, parse external data at boundaries. |
| [Make Operations Idempotent](/principles/make-operations-idempotent) | Converge to the same end state. |
| [Migrate Callers Then Delete Legacy APIs](/principles/migrate-callers-then-delete-legacy-apis) | Migrate and delete in one wave. |
| [Separate Before Serializing Shared State](/principles/separate-before-serializing-shared-state) | Eliminate the sharing first. |

## Verification

| principle | the rule |
|---|---|
| [Prove It Works](/principles/prove-it-works) | Verify against the real artifact, not a proxy or "it compiles". The proof is something the user can see. |
| [Fix Root Causes](/principles/fix-root-causes) | Trace each symptom to its root cause, reproduce first, ask why until you reach it. |
| [Sequence work into verifiable units](/principles/sequence-verifiable-units) | Small units that each end in a check, verify each before the next. |
| [Test Behavior, Not Implementation](/principles/test-behavior-not-implementation) | Call the code the way its users do and assert the result against a literal expected value. If the test would still pass when every imported function returns undefined, rewrite it or delete it. |
| [Explain the Number](/principles/explain-the-number) | Find what limits it, and rule out that it measured something other than the work you think. |

## Delegation

| principle | the rule |
|---|---|
| [Guard the Context Window](/principles/guard-the-context-window) | Route bulk to helpers, keep summaries in the main thread. |
| [Never Block on the Human](/principles/never-block-on-the-human) | Proceed, present the result, let the human course-correct. (Ideation is the deliberate exception.) |
