---
title: Proof
description: The proof pack. Evidence sized to the change, built before done and before any PR.
---

**What it does.** Builds evidence a reader can look at and believe, sized to the change, before `/shipit` says done or opens a PR.

**Why.** "It compiles" and "tests pass" are inputs, not proof. A reader who runs nothing should see that it works, or exactly where it falls short.

| change | proof |
|---|---|
| nit: typo, copy, config value, comment, dependency bump | the one check that covers it, with its command and result |
| backend: logic, API, data, CLI | the repo's checks plus one real run of the changed path |
| UI: anything that shows on a screen | light and dark screenshots of the real app, and the visual diff |
| a number | a before and after chart, with its command |
| docs only | the docs build, or the rendered page |

An opt-in `PreToolUse` hook refuses `gh pr create` when the PR body has no `## Proof` section. Add it to `~/.claude/settings.json` under `hooks`:

```json
"PreToolUse": [
  { "matcher": "Bash", "hooks": [ { "type": "command", "command": "python3 -I ~/.claude/skills/shipit/hooks/require-proof.py" } ] }
]
```
