Plain Claude Code is a strong agent with no fixed process. shipstack gives it one. Here is what that buys you, and what it costs.

## The right playbook for the task

`/shipit` matches your task to one of 22 [playbooks](/playbooks) and copies its steps into the todo list before any other work. A bug fix starts by reproducing the bug. An idea gets options and a recommendation, then stops for your pick. A PR gets driven to merge-ready but not merged. You describe the task in your own words and never name the playbook.

A step it chooses to skip stays in the list as `skip: <reason>`, so you can see what it decided not to do.

## Proof before done

Nothing is done, and no PR opens, without a [proof pack](/proof). It is sized to the change. A typo's proof is the one check that covers it. A backend change's is the repo's checks plus one real run of the changed path. A UI change gets light and dark screenshots and a visual diff. "Tests pass" is one row of the proof, never the whole of it.

An opt-in hook makes this hard to skip: it refuses `gh pr create` when the PR body has no `## Proof` section.

## A trivial lane for small edits

A typo, a config value, a one-line fix or a dependency bump takes the trivial lane. `/shipit` makes the change, runs the one check that covers it, and replies in two or three lines. No todo list, no subagents, no artifact. It escalates to a full playbook the moment the change grows.

## Review from different model families

The review panels mix families on purpose, because a second model catches what the first one is blind to.

| panel | default models |
|---|---|
| `/interrogate` reviewers | opus, sonnet, fable |
| `/arena` runners | opus, sonnet, fable |
| `/architect` runners | opus, sonnet |

`codex` is an opt-in second vendor for any of them, once `/setup-shipit` finds it on your `PATH`.

## Reading roles on Haiku

Roles that only read code or sources (`/how` explorers, `/why` investigators, recall and source readers) run on Haiku at the budget's starting effort. That default comes from a blind eval.

| arm | mean score /25 | claims wrong / checked | mean cost per run | mean time |
|---|---|---|---|---|
| Haiku `high` | 19.3 | 3 / 39 | $0.017 | 99 s |
| Haiku `xhigh` | **23.3** | 5 / 50 | $0.040 | 275 s |
| Sonnet `xhigh` | 21.0 | 2 / 46 | $0.665 | 166 s |

Haiku at `xhigh` scored highest for about a fifteenth of Sonnet's cost. It was also the slowest arm. The eval is small: three questions, one codebase, one judge. The cost gap is the robust part. Source: [`docs/evals/2026-10-explorer-models.md`](https://github.com/sean-brydon/shipstack/blob/main/docs/evals/2026-10-explorer-models.md), with the raw rows in `explorer-scores.csv` and `explorer-cost.csv`. [Models and cost](/models-and-cost#the-eval) has the full setup.

## A cost receipt

A run that spawned subagents or ran long ends with its cost. `cost.py` reads the session's transcripts and prints the total, the split by agent and by model, at list API prices. You see what the rigor cost, not a guess.

## Saved rejections are respected

At the start of every task `/shipit` reads the memories Claude Code loaded for the project. A saved rejection ("don't X", "never Y", "parked") is a constraint, not a preference. It is never re-pitched or routed around, and every subagent brief quotes the relevant lines, because a subagent may not see them.

## Fewer stalls in auto mode

A denied call is treated as an answer: logged, skipped and reported, never retried or routed around. Playbooks prefer the git forms auto mode doesn't refuse. [Auto mode](/auto-mode) has the details.

## What it costs

The rigor is not free. Subagents, review panels and proof all spend tokens.

- **A feature run costs more than a plain session.** We estimate 2 to 4 times a plain Claude Code session for a feature. This is an estimate, not a measurement. Run `cost.py` on your own sessions to see your number.
- **The trivial lane avoids most of it.** A small edit gets no subagents and no panel.
- **Reading roles on Haiku cut the biggest fan-out.** See the eval above.
- **You can turn it down.** A smaller budget in `/setup-shipit`, cheaper families in the code roles, `inherit` for a role, or a shorter panel list. Save `/shipit` for work that needs rigor.

On a subscription the dollars `cost.py` prints are usage, not a bill.
