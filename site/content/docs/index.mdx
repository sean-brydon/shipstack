**What it does.** shipstack is a set of skills for Claude Code. You type `/shipit` and a task; it picks the playbook for that kind of task, runs it, and shows proof before it calls anything done.

**Why.** Plain Claude Code has no fixed process. The same kind of task gets different steps each time, and "tests pass" stands in for proof.

## What you get, and why

- **The right checklist.** 22 [playbooks](/playbooks), picked from your words, so a bug fix always starts with a repro.
- **Proof before done.** Evidence sized to the change, from one check for a typo to light and dark screenshots for UI. [No proof, no PR](/proof).
- **Small edits stay small.** The trivial lane fixed a typo in 11 s for $0.22; a bug fix with a failing test first took under a minute for $0.40.
- **Cheap reading.** As a `/how` explorer, Haiku at `xhigh` scored 23.3/25 against Sonnet's 21.0, at about 1/15 the cost ($0.040 against $0.665 a run). [The eval](/models-and-cost#the-eval).
- **Review across model families.** `/interrogate` puts Opus, Sonnet and Fable on one diff; on this repo it found five real bugs for $6.27.
- **A cost receipt.** Runs with subagents end with their cost by agent and model. A feature run costs an estimated 2 to 4 times a plain session.
- **Rejections stick.** A saved "don't X" is never re-pitched, and every subagent brief quotes it.

## Install

```sh
git clone https://github.com/sean-brydon/shipstack ~/shipstack
cd ~/shipstack
./install.sh
```

Then start a new session and see [Getting started](/getting-started). [Runs](/runs) has eight recorded sessions to step through.
